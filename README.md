# Compendium

An autonomous, low-maintenance content engine that ingests long-form YouTube videos, generates structured masterclass syntheses using Google Gemini, stores the content in Supabase, and serves it via a high-performance Next.js publication with Incremental Static Regeneration (ISR).

---

## Architecture Overview

```text
[ Daily Schedule Trigger ]
          │
          ▼
 [ Fetch RSS Feeds ] (Lenny's Podcast, Product School, Exponent, etc.)
          │
          ▼
   [ Merge Feeds ]
          │
          ▼
[ 24h & Shorts Filter ]
          │
          ▼
[ Extract Metadata & Slug ]
          │
          ▼
[ Deduplication Check ] ◄─── [ Fetch Existing Articles from Supabase ]
          │
     (Only in A)
          │
          ▼
[ Fetch YouTube Transcript ] (youtube-transcript.ai)
          │
          ▼
[ Length Validation Filter ]
          │
          ▼
[ Gemini LLM Synthesis ] (Structured Masterclass Dossier)
          │
          ▼
[ Format Supabase Payload ]
          │
          ▼
[ Insert Row to Supabase ]
          │
          ▼
[ Live Next.js Web App ] (ISR on Vercel)
```

## Tech Stack

* **Frontend:** Next.js (App Router, TypeScript, Tailwind CSS)
* **Backend & Database:** Supabase (PostgreSQL, Row Level Security)
* **Orchestration & Workflow:** n8n
* **AI Model:** Google Gemini Chat Model
* **Transcript Source:** `youtube-transcript.ai` API

## Database Schema (Supabase)

Run the following SQL in your Supabase **SQL Editor** to create the `articles` table and configure public read access:

```sql
create table articles (
  id bigint generated by default as identity primary key,
  title text not null,
  slug text unique not null,
  channel_name text,
  content text not null,
  source_url text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Enable Row Level Security
alter table articles enable row level security;

-- Allow public read access for Next.js ISR
create policy "Allow public read access"
  on articles
  for select
  using (true);

-- Allow authenticated/service insert access
create policy "Allow insert access"
  on articles
  for insert
  with check (true);
```

### Existing Tables

If the `articles` table already exists, run this once in the SQL Editor to add the column and clean any line breaks that leaked in from the YouTube Atom `<author>` fields:

```sql
alter table articles add column if not exists channel_name text;

update articles
set channel_name = btrim(regexp_replace(channel_name, '\s+', ' ', 'g'))
where channel_name is not null;
```

## n8n Workflow Configuration

### 1. Ingestion & Pre-Processing
* **Schedule Trigger:** Set to fire once daily (e.g., `0 6 * * *` at 06:00 UTC).
* **RSS Read Nodes:** Fetch the public Atom feeds for each channel:
  ```text
  [https://www.youtube.com/feeds/videos.xml?channel_id=](https://www.youtube.com/feeds/videos.xml?channel_id=){CHANNEL_ID}
  ```
* **Merge Node:** Combines output streams into a single list (`Mode: Choose Branch / Append`).
* **In 24 Hrs & Shorts Filter:** Filters out videos older than 24 hours (`{{ $now.minus({ hours: 24 }) }}`) and rejects shorts containing `/shorts/`.

### 2. Code Node (Extract Metadata & Slug)
Extracts the clean `videoId`, standardizes metadata, and derives the URL slug upfront:

```javascript
const url = $json.link;
const match = url.match(/(?:v=|\/embed\/|\/shorts\/|youtu\.be\/)([a-zA-Z0-9_-]{11})/);
const videoId = match ? match[1] : null;

const rawTitle = $json.title || '';
const slug = rawTitle
  .toLowerCase()
  .replace(/[^a-z0-9]+/g, '-')
  .replace(/(^-|-$)+/g, '');

// YouTube Atom feeds embed line breaks inside <author><name> — collapse whitespace.
const channelName = ($json.author || $json.creator || '').replace(/\s+/g, ' ').trim();

return {
  videoId: videoId,
  title: rawTitle,
  slug: slug,
  channelName: channelName,
  link: $json.link,
  description: $json.contentSnippet || '',
  publishedAt: $json.pubDate || $json.isoDate
};
```

### 3. Deduplication Check (Dataset Comparison)
Prevents re-processing existing videos to conserve transcript credits and LLM tokens:
* **Fetch Existing Articles (Supabase Node):**
  * **Resource:** `Row`
  * **Operation:** `Get Many`
  * **Table:** `articles`
  * **Return All:** Toggle `OFF` (Limit: `100`)
  * **Filter:** None
* **Compare Datasets Node:**
  * **Input A:** Connected to `Code`
  * **Input B:** Connected to `Fetch Existing Articles`
  * **Input A Match Key:** `slug`
  * **Input B Match Key:** `slug`
  * **Branch:** Connect the **`only-in-a`** output dot directly into the `HTTP Request` node.

### 4. Transcript & LLM Synthesis
* **HTTP Request (Transcript):**
  * **Method:** `GET`
  * **URL:** `https://youtube-transcript.ai/transcript/{{ $('Code').item.json.videoId }}.txt`
* **Filter Node:** Discards empty or failed transcripts (e.g., text length `< 1000` characters).
* **Basic LLM Chain + Google Gemini Chat Model:** Prompts Gemini to synthesize the transcript into an actionable masterclass breakdown with clear sections, core frameworks, key quotes, and concrete takeaways.

### 5. Final Code Node & Database Insert
Formats the final object according to the database schema:

```javascript
const articleText = $json.text;
const firstCodeNode = $('Code').item.json;

return {
  title: firstCodeNode.title,
  slug: firstCodeNode.slug,
  channel_name: firstCodeNode.channelName,
  content: articleText,
  source_url: firstCodeNode.link,
  created_at: new Date().toISOString()
};
```

* **Create a row (Supabase Node):**
  * **Resource:** `Row`
  * **Operation:** `Create`
  * **Table:** `articles`
  * **Data to Send:** Map fields automatically from the preceding JavaScript node.

## Next.js Frontend Setup

### Environment Variables

Create a `.env.local` file in the root of your Next.js project:

```env
NEXT_PUBLIC_SUPABASE_URL=https://<your-project-id>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<your-anon-key>
```

### Local Development

```bash
# Install project dependencies
npm install

# Test compilation and static page generation
npm run build

# Start local development server
npm run dev
```

Navigate to `http://localhost:3000` to review the index catalog and `/articles/[slug]` to view individual dossiers.

---

## Deployment & Production

1. **Deploy Frontend:** Push your Next.js project to GitHub and import it into Vercel. Ensure production environment variables (`NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY`) are set under Project Settings.
2. **Activate Orchestration:** In the n8n canvas, click **Publish** in the top-right corner to activate background execution on the configured schedule.
3. **Execution Cleanup:** Under n8n workflow settings, ensure **Save successful executions** is disabled (or pruned every 24–48 hours) to prevent disk exhaustion from large transcript payloads.
